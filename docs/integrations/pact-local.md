# PACT local development

The [native PACT client](pact-client.md) handles domain-based pairing. To develop the optional legacy PactAuth adapter, check out a revision of `laravel-pact-agent` that supports the app's PACT SDK version beside this project, then run `php scripts/install-pact-local.php`. The script starts from the committed lock and adds the local adapter while keeping the versioned PACT packages. A regular Composer install removes the local adapter.

The existing PactAuth grant remains mandatory and is scoped to its approved project. Set `PACT_AUTH_ENABLED` and, only when a local PACT integration is intentionally configured, `PACT_TRANSPORT_ENABLED`. Add the exact Octodora Bot origin to `PACT_AUTH_ALLOWED_CLIENT_ORIGINS`; local HTTP also requires `PACT_AUTH_ALLOW_LOCAL_HTTP`. Run the host and package migrations and a queue worker before testing tasks. Configure the host's existing AI provider separately. Federation bootstrap requires an explicitly allowlisted coordinator origin and stores its MCP credential encrypted per grant.

Federated execution requires a committed bootstrap and the coordinator's parent task ID. Each model call reserves a shared budget step before contacting its provider; a missing connection or parent stops the task, and a rejected reservation prevents the provider call. The coordinator and provider interactions in the automated tests are simulated; live interoperability and provider execution require separately configured accounts and have not been established by those tests.

Run `php artisan pact-agent:work` for the isolated `pact_agents` connection and `pact-agents` queue. The worker handles PACT runs and session continuations without consuming the application's ordinary agent queue; the default queue configuration is unchanged.

The PACT agent may list and read the grant owner's conversations in that project. It may also ask an existing owned conversation a question: this appends a clearly marked PACT-origin turn, starts a queued child run and waits without holding a worker. The child inherits the same Federation budget and cannot recursively ask another session. A durable handoff permits recovery after queue delivery loss; cancellation and revoked grants stop the child. Session contents remain in AskMyDocs, while only the resulting answer and authorized sources can be returned to the coordinator.
