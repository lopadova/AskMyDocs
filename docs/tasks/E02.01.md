# E02.01 — ActionIntent, classificazione e digest

Status: `VERIFIED_LOCAL_PARTIAL`

## Implemented

- PHP `ActionCanonicalizer` sorts object keys recursively, preserves list order and emits a versionable SHA-256 digest.
- TypeScript frontend canonicalizer matches the PHP golden vector.
- `ActionIntent::fromModelProposal()` constructs tenant, principal, grant and assurance server-side and strips security fields from model arguments.
- `ActionRegistry` keeps unknown or unclassified tools non-executable.
- The widget `/exec-tool` path now requires a classified executable effect after the existing skill allowlist and session/tenant gates.
