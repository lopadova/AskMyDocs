# Release notes - Q3 2026

Highlights of the applications shipped in the third quarter.

## Warehouse app 3.2

- Wave picking groups orders by zone to cut walking distance by about 18%.
- The new cycle count screen shows the last three counts of a bin.
- The default request timeout is 20 seconds.

## Customer portal 5.1

- Customers can change the delivery address until the order is PICKED.
- The returns page now shows the status of the refund.
- The default request timeout is 45 seconds.

## Courier gateway 1.9

- Adds BlueRoute as a second carrier for the northern routes.
- Retries a failed carrier call once before reporting an error.
- The default request timeout is 12 seconds.

## Known issues

The customer portal 5.1 invoice download is slow for accounts with more than
2,000 invoices; a fix is scheduled for the first release of Q4.
